02 / Principles

Not another UI prompt.
A working design process.

It starts by understanding the product and its users. It then makes explicit design decisions, implements behavior, and checks the result instead of calling a pretty screenshot “done.”

01 — Context

Know what you're making.

Audience, product, user job, constraints and evidence. No invented features or filler copy.

02 — Direction

Choose a visual thesis.

Typography, palette, composition and media come from the product—not a reusable template.

03 — Execution

Ship the real experience.

Interaction states, responsive behavior, accessibility and visual QA are part of the work.

03 / Workflow

From brief to
verified interface.

A clear sequence that keeps design decisions connected to the implementation.

01 / DISCOVER
⌕

Read the room.

Inspect the product, audience, routes, constraints and current implementation.

02 / DIRECT
✳

Set the direction.

Choose the visual thesis, structure, design tokens and interaction language.

03 / BUILD
↗

Make it work.

Implement meaningful states, responsive layout and accessible interactions.

04 / VERIFY
✓

Review the result.

Check viewports, keyboard, motion, media, errors and available tests.

05 / Motion study

Motion that has
a reason to exist.

Subtle movement can guide attention, show hierarchy and make the interface feel responsive. This study is interactive—pause it, resume it, or turn motion off site-wide.

Motion / playground

One system.
Many moving parts.

Orbital rhythm, floating labels, and a central shape that reacts to hover. Movement is restrained, looped, and respects reduced-motion preferences.
